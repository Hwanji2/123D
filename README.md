# 123D
연산을 활용한 3D FPS

게임 본체는 [index.html](index.html) 한 파일입니다. (three.js는 CDN에서 로드)

## 실행

- 그냥 `index.html`을 브라우저로 열거나,
- 로컬 서버: `python3 -m http.server 8000` → http://localhost:8000

마우스가 있는 PC에서는 자동으로 **PC 모드**가 켜지고 터치 버튼이 숨겨집니다.

## 조작

| 동작 | 모바일 | PC |
|---|---|---|
| 이동 | 왼쪽 조이스틱 | WASD / 방향키 |
| 시점 | 화면 드래그 | 마우스 (화면 클릭 시 포인터 잠금, Esc로 해제) |
| 발사 | `+` 버튼 | 좌클릭 |
| 점프 (길게=높이, 2단 점프) | 점프 버튼 | Space |
| 연산자 변경 | `⟳` 버튼 | Q / E, 마우스 휠, 우클릭, 숫자키 1~9 |
| 시드 설정 | 톱니바퀴 | Tab 또는 톱니바퀴 클릭 (Enter로 적용) |
